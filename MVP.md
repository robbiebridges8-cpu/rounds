# MVP checklist

Everything in the app today, one line each. Tick means built and working in Expo Go. A dash means built but waiting on something outside the code.

Last updated 11 September 2026.

## Getting in
- [x] Welcome screen
- [x] Sign in and create account with email and password
- [x] Forgot password by six-digit code
- [x] Onboarding: username, display name, avatar
- [x] First pubs: tick the ones you already know
- [x] Delete account

## Pubs
- [x] 3,593 London pubs from OpenStreetMap, 37 seeded as classics
- [x] Map with search, filter chips, tiered dots, and a card per pub
- [x] Only pubs with activity at city zoom; everything when zoomed in
- [x] Nearby list by walking distance
- [x] Search by name
- [x] Add a missing pub
- [x] Pub page: hero photo, rating, who's been, ratings distribution, mates' quotes
- [x] Front photo for most pubs from Wikimedia Commons, credited; no placeholder pictures anywhere
- [x] Amenities: 16 tags, confirm by tap, seeded from OpenStreetMap
- [x] Report a problem with a pub

## Check-ins
- [x] Camera-first check-in: photo, stars in halves, who was there, a note
- [x] Optional amenity confirmation at check-in
- [x] Geofence: verified within 150 m, otherwise counted and marked
- [x] Tag mates on Rounds; text people who aren't
- [x] Edit the stars or note on your own check-in, or delete it, from the diary or the post
- [x] Add a visit to your map when a mate tagged you

## Social

- [x] Feed of friends' check-ins

- [x] Post page with the cheers gallery and thread
- [x] Inbox for cheers, replies, tags and the weekly digest
